What I built and why

A PySpark pipeline reconciles orders, payments, refunds, and products into Parquet analytics. Deterministic deduplication, validation, and aggregation before joins keep the revenue calculation consistent.

The repository includes four local tests, Terraform for S3, Glue, and Athena, and an optional Airflow DAG. The pipeline was tested locally; AWS infrastructure and Airflow execution have not been deployed or run for this demo.

These rows and totals match the synthetic examples in the project repository. The browser shows the finished results; it does not run Spark.

Why include the carrier that crosses the target?

A target is a minimum, not a ceiling. At 80% on ATL → JFK, DL and AA are enough. At 85%, adding UA brings coverage to 95%. Stopping before UA would miss the target.

The Python and SQLite project uses cumulative SQL rankings. This browser version makes the same selection visible as you move the slider.

Synthetic flight shares, used to explain ranking and coverage. They do not represent current flight schedules or measured production savings.
